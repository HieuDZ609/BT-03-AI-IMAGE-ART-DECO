## 1. MỤC TIÊU VÀ NHIỆM VỤ ĐƯỢC PHÂN CÔNG (THEO KẾ HOẠCH MỚI)
1. **Kiến trúc phân tán 5 VM**:
   - VM4 (Nhóm trưởng): Core Node (Gateway + Redis Streams + Postgres + MinIO + Nginx + Frontend).
   - VM2 (Máy B4.2 - IP `192.168.100.12`): Chạy **AI Worker 2.1** stateless.
   - B4.2 đồng thời chịu trách nhiệm hoàn thiện module **Data & Storage** (`image-service` + database schema + chống trùng lặp + API) để bàn giao tích hợp vào cụm máy chủ.
2. **Quy chuẩn phong cách ảnh ART DECO**:
   - Tuân thủ file dùng chung `packages/shared/style.yaml`.
   - Bảng màu: Antique Gold (`#C9A227`), Cream (`#F4EAD5`), Muted Teal (`#1E6E6B`), Deep Black (`#18181B`).
   - Bố cục: Viền Stepped Chevron + Sunburst corner motifs, 1 chủ thể duy nhất ở trung tâm chiếm $\ge 60\%$ khung hình, nền trơn cream, tuyệt đối không có chữ.
3. **Quy chuẩn đặt tên và chống trùng lặp**:
   - `image_name = "{slug} {member_id}.{worker_index}.{ext}"` (Ví dụ: `black dog 2.1.png`, `red hat 2.1.jpg`).
   - `storage_key = "{slug}/{ai_code}/{uuid4hex}.{ext}"` (Khóa MinIO S3 không bao giờ ghi đè).
   - Chống trùng lặp 2 lớp: Unique index `(slug, ai_code)` và `sha256: unique`.
4. **Quy chuẩn API (OpenAPI 3 · Prefix `/api/v1`)**:
   - `GET /api/v1/images?page=1&size=50`: Phân trang 50 ảnh mới nhất trước.
   - `GET /api/v1/search?q=...&page=1`: Tìm kiếm theo tên; nếu miss tự động sinh trong phiên hoặc trả job xếp hàng, **không bao giờ trả "không có kết quả"**.
   - `GET /api/v1/statistics`: Thống kê số lượng ảnh chi tiết theo từng AI Worker.
   - `POST /api/v1/images`: Tiếp nhận ảnh từ các AI Workers nộp vào kho.
   - `POST /api/v1/generate`: Kích hoạt sinh ảnh Art Deco tức thì.

## 2. THIẾT KẾ CƠ SỞ DỮ LIỆU & SCHEMA
Hệ thống sử dụng cấu trúc quan hệ chuẩn tương thích PostgreSQL 16:
- **`members`**: `(member_id PK, student_code, full_name, role, is_leader)`
- **`ai_workers`**: `(worker_id PK, member_id FK, ai_code UNIQUE, model_name, model_version, hostname, status, last_heartbeat, total_generated)`
- **`images`**: `(image_id UUID PK, image_name, slug, prompt, style_id, worker_id FK, ai_code, storage_key UNIQUE, sha256 UNIQUE, width, height, format, file_size, file_url, created_at)`
- **`generation_jobs`**: `(job_id UUID PK, query, slug, source, status, worker_id, attempts, queued_at, started_at, finished_at, duration_ms, image_id, error)`
- **`search_logs`**: `(log_id PK, query, hit, job_id, created_at)`
